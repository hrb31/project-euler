# Project Euler Solutions

A collection of my Python solutions to selected [Project Euler](https://projecteuler.net/) problems.

I'm using Project Euler to improve my:

- Python programming
- Mathematical problem-solving
- Algorithmic thinking
- Understanding of efficiency and optimisation
- Ability to turn mathematical ideas into code

## Approach

For each problem, I try to:

1. Understand and solve the mathematical problem first.
2. Write my own Python solution.
3. Test and debug the implementation.
4. Consider whether the solution can be made more efficient.
5. Learn any new algorithms or mathematical techniques that arise.

The goal is not simply to complete as many problems as possible, but to improve the way I approach computational problems.
